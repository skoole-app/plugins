# Qualifier un prospect : ce qui se vérifie avant de vendre

Format : quiz Skoole v1
Identifiant : exemple-qualification-prospect
Usage : formatif
Duree : 8 min
Melanger les questions : non
Melanger les options : oui

## Q1. Qualifier un prospect, c'est d'abord :
- [x] Vérifier s'il a un besoin, un budget, un décideur et une échéance
- [ ] Présenter l'offre complète pour susciter l'intérêt
- [ ] Obtenir une adresse électronique pour la liste de diffusion
- [ ] Faire une remise pour accélérer la signature
> Qualifier, c'est décider si on continue. La présentation vient après, et seulement sur ce qui répond au besoin entendu.

## Q2. Parmi ces informations, lesquelles font partie de la qualification ? (plusieurs réponses)
Points : 2
- [x] L'échéance à laquelle le problème doit être réglé
- [x] La personne qui signe la commande
- [ ] La couleur préférée de l'interlocuteur
- [ ] Le nombre de pages du site de l'entreprise
> L'échéance et le décideur conditionnent la suite ; les deux autres n'engagent aucune décision d'achat.

## Q3. Un appel de qualification peut se terminer sans date de rappel.
- [ ] Vrai
- [x] Faux
> Un appel sans engagement daté laisse la relation à la mémoire des deux parties, et elle s'efface en une semaine.

## Q4. Comment appelle-t-on la phrase qui redit au prospect ce qu'on a compris de son besoin ?
Reponses acceptees :
- reformulation
- la reformulation
Tolerance : normale
> La reformulation est le seul moyen de vérifier qu'on a entendu, et elle fait dire au prospect « c'est exactement ça ».

## Messages de fin
- 0 % : Point de départ noté. Ces quatre critères sont le cœur du module.
- 50 % : Les bases tiennent, la conduite de l'appel reste à travailler.
- 80 % : Solide. Sois exigeant sur la trace écrite après l'appel.
