# Les plugins Skoole

Le connecteur qui permet à l'agent Claude d'un formateur de travailler
directement dans sa plateforme [Skoole](https://skoole.app). **Rien dans ce
dépôt n'est secret** : le formateur autorise la connexion dans son navigateur
et la révoque d'un clic dans Skoole.

Le mode d'emploi complet (installer, se connecter, les onze outils, les sept
compétences, ce qui change à chaque version) est dans
[`plugin/README.md`](plugin/README.md).

```
/plugin marketplace add skoole-app/plugins
/plugin install skoole@skoole
```
